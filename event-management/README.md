# Eventia — Event Management Web App

A premium, modern event management application: discover events, register for them,
track stats on a dashboard, and manage events as an admin — all in one deployable app.

## Tech Stack

- **Frontend:** React + Vite + JavaScript, Tailwind CSS v4, hand-built shadcn/ui-style
  components (Radix primitives), React Router
- **Backend:** Node.js + Express (REST API)
- **Data:** In-memory JSON store (no database) — seeded with 12 realistic events
- **Deployment:** Express serves the Vite production build as a single app on one port

## Project Structure

```
event-management/
├── client/           # React + Vite frontend
│   ├── src/
│   │   ├── components/  # ui/ (design system), layout/, events/
│   │   ├── pages/        # Home, EventDetails, Dashboard, Admin, NotFound
│   │   ├── data/          # category metadata
│   │   └── lib/            # api client, utils, formatters
├── server/           # Express backend
│   ├── routes/        # events.js, stats.js
│   ├── data/            # in-memory events.js store
│   ├── public/            # built client (generated by `npm run build`)
│   └── index.js
└── package.json      # root orchestration scripts
```

## Features

- **Discover** — searchable, filterable, sortable event grid with a hero and featured
  events, polished loading/empty/error states
- **Event Details** — full event info, live capacity bar, registration dialog with
  validation and confirmation
- **Dashboard** — key metrics (registrations, fill rate, revenue, category breakdown,
  events needing attention) and top popular events
- **Admin** — full CRUD for events (create/edit/delete) and a per-event registrations
  viewer, in a responsive data table

## Run locally

```bash
# from the repo root
npm run install:all   # installs client + server deps
npm run build          # builds the React app into server/public
npm start                # starts Express on http://localhost:5000
```

For active frontend development with hot reload (proxies /api to the Express server):

```bash
npm run dev:server    # terminal 1 — API on :5000
npm run dev:client     # terminal 2 — Vite dev server on :5173
```

## Deployment

This is a single deployable Node app. Any host that runs `npm install`, `npm run build`,
then `npm start` (e.g. Render, Railway, Fly.io, a VPS) will work — Express serves both
the API (`/api/*`) and the built React app on the same port.

> Note: data is stored in memory and resets on server restart — by design, for this
> competition build. Swap `server/data/events.js` for a real database later without
> touching the API routes.
